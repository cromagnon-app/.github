## What is Cromagnon?

[Cromagnon](https://cromagnon.app) is a set of ten full workspaces ("studios") and more than 80 single-purpose tools for everyday file work. It is built for people everywhere: students, teachers, freelancers, small businesses and office teams.

- **Your files stay on your device.** Opening, editing, converting and exporting happen in the browser tab. Files are not uploaded to our servers.
- **Free, with every feature unlocked.** No watermarks, no trial limits, no paid plan needed to use a studio.
- **No account needed.** Signing in is optional and only adds sync between your devices.
- **Works offline** once a page has loaded, and can be installed as an app.
- **Real file formats.** DOCX, XLSX, PPTX, PDF, CSV, APKG and more, opened and saved as the real thing.

## Privacy, in short

- Files are processed by code running in your browser. Only a few optional features that need the internet (for example looking up a citation from a web address) send the minimum needed, and say so.
- No ads between your work, and no selling of data.
- Read the full [privacy policy](https://cromagnon.app/privacy).
